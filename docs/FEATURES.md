## 核心產品流程

### 旅行與記帳

1. 建立旅程並加入真人或虛擬成員。
2. 設定常用幣別、自己的旅程預算與每日行程。
3. 從旅行頁或全域「記一筆」新增支出，送出前確認付款人、分攤與換算結果。
4. 在結算頁查看轉帳建議並登記實際還款。

旅行空間固定為四個主分頁：行程、支出、相簿、結算。`/trips/[id]` 是行程落點，不是支出頁。

### 分享

| 分享類型 | 能看到 | 刻意不公開 |
| --- | --- | --- |
| 旅行分享 | 旅程、行程、支出、統計、結算、清單 | 個人預算、收據附件、成員限定筆記 |
| 地圖/回顧/徽章 | 去識別化彙總、座標、地名、年份 | 旅程名稱、ID、完整日期、精確金額 |
| 相簿分享 | 相片、說明、日期、旅程名 | 位置、地名、EXIF、上傳者、內部 key |

`/api/public/*` 是刻意未登入的唯讀分享介面。隱私與 DTO 契約見 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 使用限制

- **AI 智慧輸入**：行程文字匯入限旅程 admin；成員可用自然語言或收據圖片產生支出草稿。結果須經預覽、修正與明確確認才寫入；支出草稿支援四種分攤方式，歧義須人工確認。收據分析支援 JPEG、PNG、WebP，PDF 僅作一般附件。目前維持低流量受限試用，未設定 AI provider 時停用解析。
- **離線**：可讀取已快取資料，並離線新增支出、顯示待同步狀態及恢復連線後補送。編輯、刪除、結算與統計重算仍需連線。
- **相簿**：成員版 JPEG 保留 GPS EXIF，公開分享使用移除 EXIF 的副本。相片可採用關聯行程日座標；只有 EXIF 座標的相片可能沒有地名標籤。
- **個人統計**：依個人分攤金額分析，可用日期、分類、旅程與標籤篩選，並連動分頁明細；篩選狀態可由 URL 還原。
- **旅行成就與會籍**：飛行與住宿為終身紀錄，刪除旅程只解除關聯。會籍提供積分記帳與門檻進度，試算依內建規則，不保證等同航空公司最終認定。
- **外部服務**：附件需要 R2，Email 需要寄信服務，Web Push 需要 VAPID 與裝置授權；實際可用性依部署設定而定。
