## 核心產品流程

### 旅行與記帳

1. 建立旅程並加入真人或虛擬成員。
2. 設定常用幣別、預算與每日行程。
3. 從旅行頁或全域「記一筆」新增支出，送出前確認付款人、分攤與換算結果。
4. 在結算頁查看轉帳建議並登記實際還款。

旅行空間固定為四個主分頁：行程、支出、相簿、結算。`/trips/[id]` 是行程落點，不是支出頁。

### 分享

| 分享類型 | 能看到 | 刻意不公開 |
| --- | --- | --- |
| 旅行分享 | 旅程、行程、支出、統計、結算、清單 | 收據附件、成員限定筆記 |
| 地圖/回顧/徽章 | 去識別化彙總、座標、地名、年份 | 旅程名稱、ID、完整日期、精確金額 |
| 相簿分享 | 相片、說明、日期、旅程名 | 位置、地名、EXIF、上傳者、內部 key |

`/api/public/*` 是刻意未登入的唯讀分享介面。隱私與 DTO 契約見 [ARCHITECTURE.md](./ARCHITECTURE.md) 與 [claude/ARCH-NOTES.md](./claude/ARCH-NOTES.md)。

## 特殊功能說明

### 檔案與相簿

- 收據與票券存私有 R2 bucket；頭像存公開 bucket。
- 相簿顯示用 JPEG 刻意保留 GPS EXIF，供下載回手機後保留地點。
- 公開相簿只簽移除 APP1/EXIF 的 `_p.jpg` 消毒副本與 `_t.webp` 縮圖，絕不簽原始顯示檔。
- 相片可借用關聯行程日座標；EXIF 或手動座標不會被較低精度的行程座標覆蓋。

### 離線

- Service worker 快取頁面與靜態資源；TanStack Query 快取持久化到 IndexedDB。
- 目前只有「新增支出」支援離線寫入。編輯、刪除、結算與統計重算仍需連線。
- 暫存支出會顯示待同步狀態；恢復連線後重放並更新相關查詢。

### 旅行成就與會籍

- 飛行與住宿是使用者層級終身紀錄；刪除旅程只解除關聯，不刪紀錄。
- 徽章由彙總數字推導，已發布的 badge ID 不應更名。
- 會籍定位是「積分記帳與門檻進度」，不是保證正確的航空計算器；規則常數與查證日期集中在 `src/constants/loyalty.ts`。
- 會籍 badge 色彩規則見 [TIER-COLORS.md](./TIER-COLORS.md)。

### 個人統計

- 預設檢視本月，支援近 30 天、今年、全部及自訂日期；期間、比較、分析維度與圖表選取可由 URL 還原。
- 四張洞察卡摘要總支出、每日平均、旅程數和最大分類；金額維持目前使用者的個人分攤口徑。
- 趨勢圖支援金額／筆數、日／週／月切換，以及本期和上一等長期間比較。
- 圖表時段與分類／旅程／標籤分析列可連動篩選支出明細；明細支援日期／金額排序，並可直達指定支出的編輯流程。
- 手機日期快捷選項具備至少 44px 觸控高度與明確選取狀態；自訂日期採窄版友善排版，圖表和資料點列可水平觸控滑動。
- 無支出時可直接記帳或查看全部期間；載入失敗可重試，背景更新失敗則保留上次資料。
- 詳細交付狀態與後續改善見 [PERSONAL_STATS_DASHBOARD.md](./PERSONAL_STATS_DASHBOARD.md)。

- 公開 API 限流、actions 整合測試與大型旅程分頁仍待處理；見 [IMPROVEMENTS.md](./IMPROVEMENTS.md)。
