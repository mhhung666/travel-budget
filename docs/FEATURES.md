## 核心產品流程

### 旅行與記帳

1. 建立旅程並加入真人或虛擬成員。
2. 設定常用幣別、自己的旅程預算與每日行程。
3. 從旅行頁或全域「記一筆」新增支出，送出前確認付款人、分攤與換算結果。
4. 在結算頁查看轉帳建議並登記實際轉帳（還款或預付款）。

旅行空間固定為四個主分頁：行程、支出、相簿、結算。`/trips/[id]` 是行程落點，不是支出頁。

- **旅行列表**：分「目前旅行／已封存」；旅行中與即將出發的旅行置頂。卡片標示即將出發、旅行中、待結算、已結清（依「我的」結算餘額），摘要顯示我的花費／預算或應收／應付，並可直接記一筆、查看行程或結算。
- **記帳表單**：標題下常駐「記到：旅行名稱」（全域記一筆可切換旅行，表單有內容時說明草稿會留在原旅行；在旅行內按「記一筆」直接記到這趟）；金額、描述、分類之後直接露出付款人、日期與分帳摘要，匯率／標籤／行程日收在「更多設定」。「一句話記帳」「掃描收據」預設只是兩個小按鈕，點了才展開輸入框與說明，再點一次收起。
- **行程頁**：精簡頁首一列顯示目的地與日期，一句狀態依階段顯示倒數與清單、今天的下一個活動（全部過時顯示「今日行程已結束」）與今日花費，或待結算金額；兩天以上有黏性 Day 切換列；活動與行程日的編輯／刪除收在「⋯」。
- **支出與結算**：支出分頁分「支出明細／花費分析」；花費分析的每日花費依行程日、趨勢圖依付款日；「平均每人每日」與分攤同樣保留小數，旅行未設日期時天數依首筆到末筆支出日期計算並加註。結算轉帳按鈕依身分顯示「確認已收到」「我已付款」或「標記已付」。沒有轉帳時分「尚無需要結算的支出」（成員可直接記第一筆）、「目前無需互相轉帳」和登記轉帳後的「已全部結清」；沒有支出與轉帳時，成員餘額標「尚無分攤」，「轉帳與還款紀錄」提示可先登記訂金或代墊款。登記轉帳時收款人選單不列出付款人，付款人與收款人相同或旅行只有一位成員時即時提示並停用登記；轉帳只調整結算餘額，不新增旅遊支出。

## 使用限制

- **AI 智慧輸入**：行程文字匯入限旅程 admin；成員可用自然語言或收據圖片產生支出草稿。結果須經預覽、修正與明確確認才寫入；支出草稿支援四種分攤方式，歧義須人工確認。收據分析支援 JPEG、PNG、WebP，PDF 僅作一般附件。目前維持低流量受限試用，未設定 AI provider 時停用解析。
- **離線**：可讀取已快取資料，並離線新增支出、顯示待同步狀態及恢復連線後補送。編輯、刪除、結算與統計重算仍需連線。
- **相簿**：成員版 JPEG 保留 GPS EXIF，公開分享使用移除 EXIF 的副本。相片可採用關聯行程日座標；只有 EXIF 座標的相片可能沒有地名標籤。
- **金額**：預算列「我的花費」、結算「應分攤」與個人／群組統計都是本人分攤金額的加總，各頁一致；「已付款」是代墊金額，待收／待付在結算頁。TWD 金額與分攤存到分，分攤尾差以最大餘數法分配，加總必等於支出金額；所有幣別（含 JPY）顯示最多兩位小數、省略末尾的零，表單、詳情與結算不另外取整，外幣換算參考金額標「約」；原幣與匯率保留輸入值，TWD 為換算後取到分。分攤不平衡超過尾差範圍或分給非成員的舊資料不會自動重新分配。
- **個人統計**：依個人分攤金額分析，可用日期、分類、旅程與標籤篩選，並連動分頁明細；篩選狀態可由 URL 還原。
- **旅行成就與會籍**：飛行與住宿為終身紀錄，刪除旅程只解除關聯。飛行表單的機場搜尋依代碼完全吻合、代碼前綴、名稱／城市開頭、包含排序；出發與抵達機場相同時即時提示並停用儲存，舊紀錄須修正後才能再儲存。會籍提供積分記帳與門檻進度，試算依內建規則，不保證等同航空公司最終認定。
- **外部服務**：附件需要 R2，Email 需要寄信服務，Web Push 需要 VAPID 與裝置授權；實際可用性依部署設定而定。
