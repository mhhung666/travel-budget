# AI 格式相容性與資料流程修正 — 2026-09-18

本次完成原評估建議的前兩項：將 GPT-5 mini 的結構化輸出相容性正式整合，以及修正五項可重現的程式缺陷。未調整推理強度、總額歧義提示或確認流程。本次修正以 patch 版本提交，版本以 `package.json` 為準；未部署。

## 正式程式的變更

- 文字與收據 provider 會辨識直接 OpenAI，以及 Gateway 的 `openai/` 模型。選填欄位改為必填但可為 `null`；文字分帳以互斥的 `anyOf` 分支表示。輸出先驗證 OpenAI 合約，再轉回原有草稿合約。其他模型保留原 schema。
- schema 從原欄位定義延伸，保留字數、金額、陣列長度、額外欄位等限制。收據 warnings 的選填 field 也處理 nullable。
- 文字草稿切換幣別會更新匯率：TWD 為 1，其他幣別優先使用旅程自訂匯率，其次即時匯率。沒有匯率時清空並由既有驗證阻止送出；幣別未變時保留手動匯率。
- 收據使用應用程式共用的完整支援幣別集合，GBP 不再被丟棄。
- 文字草稿的 date／itineraryDate 驗證實際日曆日期，無效值移除並提示修正；合法閏日保留。
- 文字草稿的幣別驗證共用集合，移除 ZZZ 等無效值並提示修正。
- 行程依時間排序時同步重映射模型警告索引，之後才產生並去重本地警告；相同時間維持原順序，未修改輸入。

格式依據：[OpenAI Docs — Structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs)。

## 驗證

- 19 個離線測試檔、222 項測試通過。原本五項預期失敗案例改為正常回歸測試，並補上自訂匯率、保留手動匯率、缺匯率、切回 TWD、閏日、多天警告重映射與去重等案例。
- SDK 實際輸出的 JSON schema 遞迴檢查：沒有 oneOf、所有物件欄位 required、additionalProperties 為 false。所有 75 個文字／收據 fixture 均可往返轉換；不合法必填 null、額外欄位、分帳分支與警告欄位仍被拒絕。
- 本次修改檔案 ESLint、原始碼 TypeScript 檢查通過。完整 TypeScript 檢查仍受既有 `.next` 產生檔引用不存在的 memberships 頁面阻擋，未宣稱完整 build 通過。
