# 可用性測試提綱

狀態：腳本備妥，尚未招募或執行。建議 5–7 人、每人 35–45 分鐘，涵蓋新手與有分帳經驗者，使用虛構資料。

## 任務

1. 建立旅行、加入成員並記第一筆支出。
2. 從全域入口快速記帳，確認旅行／付款人／分攤。
3. 尋找行程、支出、相簿與結算，修正一筆錯帳。
4. 斷網新增、恢復連線，理解 pending／失敗／成功狀態。
5. 透過邀請登入並返回原旅行。

## 記錄與判斷

每項只記完成／失敗、耗時、錯誤、提示次數與一句匿名回饋。主持人不先提示按鈕位置；需錄影先取得同意，不保存真實帳務或帳號資料。

確認手機、鍵盤與至少一套輔助科技；自動化 axe 通過不能取代真人結果。優先處理金額錯誤、資料遺失與無法完成，其次是需要提示才能繼續。
