## 核心產品流程

### 旅行與記帳

1. 建立旅程並加入真人或虛擬成員。
2. 設定常用幣別、自己的旅程預算與每日行程。
3. 從旅行頁或全域「記一筆」新增支出，送出前確認付款人、分攤與換算結果。
4. 在結算頁查看轉帳建議並登記實際轉帳（還款或預付款）。

旅行空間固定為四個主分頁：行程、支出、相簿、結算。`/trips/[id]` 是行程落點，不是支出頁。

- **旅行列表**：分「目前旅行／已封存」；旅行中與即將出發的旅行置頂。卡片標示即將出發、旅行中、待結算、已結清（依「我的」結算餘額），摘要顯示我的花費／預算或應收／應付，並可直接記一筆、查看行程或結算。
- **記帳表單**：標題下常駐「記到：旅行名稱」（全域記一筆可切換旅行，表單有內容時說明草稿會留在原旅行；在旅行內按「記一筆」直接記到這趟）；金額、描述、分類之後直接露出付款人、日期與分帳摘要，匯率／標籤／行程日收在「更多設定」。「一句話記帳」「掃描收據」預設只是兩個小按鈕，點了才展開輸入框與說明，再點一次收起。
- **行程頁**：精簡頁首一列顯示目的地與日期，一句狀態依階段顯示倒數與清單、今天的下一個活動（全部過時顯示「今日行程已結束」）與今日花費，或待結算金額；兩天以上有黏性 Day 切換列；活動與行程日的編輯／刪除收在「⋯」。新增行程日時先選日期（旁邊顯示對應 Day N，14 天以內的旅程列出全部日期的快捷選項並標示已建立），可跳著建立 Day 1、Day 3 而不產生空白日；刪除一天不會重編其餘天數的編號與日期。旅程未設開始日期時改填「第幾天」。
- **行程 PDF**：從匯出選單選擇已建立的日期，下載可搜尋文字的 A4 行程；可包含每日說明，成員可另選訂位確認碼（預設不含）。產檔前重新讀取已儲存資料，需連線；圖片與票券附件不收錄，Markdown 表格採簡化版面，未支援字元明示 Unicode 編碼。
- **支出與結算**：支出分頁分「支出明細／花費分析」；花費分析的每日花費依行程日、趨勢圖依付款日；「平均每人每日」與分攤同樣保留小數，旅行未設日期時天數依首筆到末筆支出日期計算並加註。成員結算以成員 ID 判斷本人、提醒對象與轉帳預填；同名成員的登記選單附 ID 尾碼。結算轉帳按鈕依身分顯示「確認已收到」「我已付款」或「標記已付」。沒有轉帳時分「尚無需要結算的支出」（成員可直接記第一筆）、「目前無需互相轉帳」和登記轉帳後的「已全部結清」；沒有支出與轉帳時，成員餘額標「尚無分攤」，「轉帳與還款紀錄」提示可先登記訂金或代墊款。登記轉帳時收款人選單不列出付款人，付款人與收款人相同或旅行只有一位成員時即時提示並停用登記；轉帳只調整結算餘額，不新增旅遊支出。

## 使用限制

- **AI 智慧輸入**：行程文字匯入限旅程 admin；成員可用自然語言或收據圖片產生支出草稿。結果須經預覽、修正與明確確認才寫入；支出草稿支援四種分攤方式，歧義須人工確認。收據分析支援 JPEG、PNG、WebP，PDF 僅作一般附件。目前維持低流量受限試用，未設定 AI provider 時停用解析。
- **離線**：可讀取已快取資料，並離線新增 TWD 帳本支出、顯示待同步狀態及恢復連線後補送；非 TWD 新增需連線，未確認內容可存草稿。編輯、刪除、結算與統計重算仍需連線。
- **相簿**：成員版 JPEG 保留 GPS EXIF，公開分享使用移除 EXIF 的副本。相片可採用關聯行程日座標；只有 EXIF 座標的相片可能沒有地名標籤。
- **金額**：預算列「我的花費」、結算「應分攤」與個人／群組統計都是本人分攤金額的加總，各頁一致；「已付款」是代墊金額，待收／待付在結算頁。旅程固定的基準幣金額與分攤存到分，分攤尾差以最大餘數法分配，加總必等於支出金額；所有幣別（含 JPY）顯示最多兩位小數、省略末尾的零，表單、詳情與結算不另外取整，原幣與匯率保留輸入值，基準幣為換算後取到分；結算／統計只顯示基準，不轉成第三種幣別。分攤不平衡超過尾差範圍或分給非成員的舊資料不會自動重新分配。
- **個人統計**：依帳本幣別分組再分析個人分攤金額，不混加或跨組排序；年度回顧同樣選擇幣別，可用日期、分類、旅程與標籤篩選，並連動分頁明細；篩選狀態可由 URL 還原。
- **旅行成就**：飛行與住宿為終身紀錄，刪除旅程只解除關聯。飛行表單的機場搜尋依代碼完全吻合、代碼前綴、名稱／城市開頭、包含排序；出發與抵達機場相同時即時提示並停用儲存，舊紀錄須修正後才能再儲存。會籍功能（`/memberships`）已下線。
- **外部服務**：附件需要 R2，Email 需要寄信服務，Web Push 需要 VAPID 與裝置授權；實際可用性依部署設定而定。

AI 三種功能的實作狀態、已知限制與驗證範圍見 [AI 維護與測試](AI.md)。

## 手機用戶端串接

E2 已加入匿名註冊、Email 六位碼寄送／重設；Web 與 Mobile 共用 `accountEntry.ts`、不分大小寫唯一帳號／Email、新密碼六字元及 72 UTF-8 bytes 上限、滑動限流。重設碼 15 分鐘／五次錯誤上限，原子更新密碼與消耗碼；仍可用的碼不因重寄更換或延長期限；錯碼滿五次鎖死後可於上次寄碼 60 秒後重寄，仍受每小時五次上限；寄信失敗也須等 15 分鐘間隔。驗證碼不印 log。手機註冊回登入頁，Web 維持 cookie adapter，cookie 失敗不推翻已建立帳號；重設後舊 Mobile session 失效，Web cookie 不宣稱全撤銷。

已新增原生用戶端 `/api/v1`：既有帳號登入、裝置憑證更新／撤銷、本人資訊、成員旅行列表與受限摘要、支出清單／明細與結算（唯讀），以及線上新增支出的成員資料、均分預覽、冪等新增與結果查詢（TWD、勾選成員均分；手機已使用）。Web cookie 與手機 session 分開；共用既有憑證檢查、旅行讀取、金額規則與同一個新增支出服務。Web 新增因此也拒絕不存在的日曆日（如 2 月 31 日）、重複的分攤成員與超過單筆上限 1,000,000,000 TWD 的金額；請求 key 不分大小寫（同一個 UUID 的任何拼法都是同一個請求），receipt 沿用舊格式，升級前的紀錄仍可重播。這是原始碼能力，不表示已部署或完成真機驗收。契約與限制見 [手機 API](MOBILE_API.md)。

Mobile E3 提供線上基本資料／明確 TWD 重新均分與刪除，與 Web 共用後端維護模組；版本前條件防止手機覆蓋 Web 新內容，UUID receipt 供結果不明恢復。Web 既有進階編輯欄位與協作權限保留；詳見 [Mobile E3 契約](../../mobile/docs/BACKEND_CONTRACT.md#e3-支出維護)。

E4 還款後端已抽成 Web／Mobile 共用服務，Web 同步驗證 0.01–1,000,000,000.00 TWD 與最多兩位小數，通知／動態原子提交，提交後快取或外部通知失敗不推翻成功；Mobile 的結算前條件／UUID 恢復見 [E4 契約](../../mobile/docs/BACKEND_CONTRACT.md#e4-登記與撤銷還款)。尚未部署，裝置驗收另行交接。
