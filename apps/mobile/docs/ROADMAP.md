# Mobile 開發路線

## 目前優先

- **跨日活動（CD4）**：Web 與 iOS 表單／確認畫面已驗。下一項是用隔離測試憑證匯入兩份 AI 草稿，核對明確日期與僅有時刻的差異。已驗環境、證據與暫緩案例見 [CD4 驗收進度](../../../docs/design/ITINERARY_PRESENTATION.md#cd4-驗收進度)。

## 接續

| 工作                            | 交付或驗收入口                                                                                                       |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 同日活動多選（BD1／BD2）        | [收尾清單](../../../docs/design/ITINERARY_BATCH_DELETE.md#本項目收尾)，核對 CI、兩端操作與真網路恢復。               |
| 我的旅行（T／UX-T3）            | [跨端核對](../../../docs/design/MY_TRIPS.md#ux-t3-待驗證)，用同資料比對列表、封存與快捷記帳。                        |
| 帳號、旅行管理與版面（M／G／U） | [本機驗收](LOCAL_ACCEPTANCE.md)，依功能補 iOS、閱讀器、附件與外部郵件核對。                                          |
| 跨端帳務（B4）                  | [固定帳務案例](LOCAL_ACCEPTANCE.md#b4-固定帳務案例)，核對舊資料恢復、精確金額與公開輸出。                            |
| 後續功能                        | 依序為行程與記帳整合（從活動記帳、保留既有草稿與歷史關聯）、站內通知收件匣（未讀數、已讀與授權導向）。兩項均待排期。 |

## 暫緩與未排程

- 原生交付 F 依序為環境隔離與自有開發包 → 帳號恢復與 Email 配額 → 帳號刪除 → 試用包 → 真機及升級驗收。啟動前確認擁有者、App 識別碼、測試網域與簽章；刪除前須定案共享帳務、唯一管理員、附件與本機待處理資料的保存政策。[原生建置](DEVELOPMENT.md#原生建置與發布) · [帳號恢復限制](BACKEND_CONTRACT.md#e2-註冊與-email-驗證碼重設)
- Android 裝置、C／D 剩餘閱讀器及對外測試依原決定暫緩。[剩餘驗收](LOCAL_ACCEPTANCE.md#尚未完成的驗收)
- 跨日多選、多選整天、原生推播、目的地搜尋、原生成員認領／邀請連結、相簿／地圖、個人洞察與 AI 尚未排程。外幣或非均分離線自動送出、離線編輯、背景同步及共用鍵盤／可見性重構也留待後續評估。
