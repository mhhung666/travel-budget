## 交付規則

- 實作與驗收分開；交接只需範圍、必要決策、實際測試結果與未驗項目。驗收分「通過／需修正／受環境限制未驗」，不以 mock 或 bundle export 取代裝置證據。
- 執行受影響測試與 Mobile check／export；跨 workspace 交付依 [開發規範](../../../docs/DEVELOPMENT.md) 執行根檢查、測試與 build。契約改動產生並檢查 OpenAPI；資料庫寫入用隔離真 DB 驗證。
- 更新受影響的現況文件與根 `changelog.md`；已完成項目合併至 [archive](archive/README.md)，roadmap 保留待辦，細節查 Git，不新增逐輪報告。commit／push／版本與發布依 repository 規則及使用者指示處理。
