# 現有功能

已實作「既有帳號登入 → 旅行列表 → 旅行摘要」的第一個唯讀切片，後端位於同一 repository 的 `apps/web`。手機與後端共用 `@travel-budget/contracts` API schema。這是程式實作狀態，不代表已部署或已通過真機驗收。

- 使用網站既有的帳號／密碼登入；access token 僅存記憶體，refresh token 存在以 API 環境隔離的 SecureStore。
- 重開 App 時更新憑證並恢復登入；登入過期／撤銷會清除私人快取。更新憑證採單一併發請求，每次 API 最多因 401 更新並重送一次。
- 更新後的 refresh token 若無法寫入 SecureStore，會清除不可再使用的舊憑證與私人快取，並嘗試撤銷新憑證；清除成功後回到登入頁，儲存空間仍無法清除時顯示錯誤並提供重試。舊登入恢復／登出結果不會覆蓋後續登入。
- 旅行列表顯示名稱、目的地、日期、個人分攤金額與狀態。旅行中優先，其次即將出發；個人封存旅行排最後。每頁 20 筆，支援載入更多與下拉更新。
- 旅行摘要顯示日期、角色、人數、支出筆數、本人分攤花費、應收／應付、今日全團花費及本人的總預算。金額皆為後端既有 TWD 計算結果。
- 支援載入、空資料、錯誤、重試、離線提示、前景／網路恢復時查詢更新；已載入資料只保留於本次執行的記憶體。
- 四語系（繁中、簡中、英文、日文）、深淺色、安全區域、文字縮放、鍵盤表單與無障礙按鈕標籤。
- 登出先撤銷伺服器 session，再刪除 SecureStore 及取消／清除私人查詢；重複點擊合併為一次登出。無法連線時保留登入並提示重試，不宣稱遠端已登出。

Web 匯出只提供介面預覽，登入明確停用；不把憑證降級存到 localStorage。原有網站仍是完整 Web 用戶端。

尚未提供手機註冊、建立／加入旅行、記帳寫入、支出明細、結算操作、行程編輯、附件、SQLite 離線儲存、推播或帳號刪除。摘要中的後續功能說明不會假裝是可操作入口。

已有 API client／session 行為測試與 CI。App ID、簽章、EAS、商店資訊及正式圖示尚未設定。原生打包匯出不等於原生編譯；iOS／Android 裝置驗收仍待執行，見 [開發規範](DEVELOPMENT.md)。
