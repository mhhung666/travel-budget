# 現有功能

已實作註冊／Email 驗證碼重設密碼，以及「帳號登入 → 旅行列表 → 旅行摘要 → 支出清單／明細 → 結算」的閱讀流程，以及旅行建立／加入、線上支出維護與還款／撤銷、線上新增支出（TWD／外幣、均分／固定金額／百分比／份數）、不確定結果恢復與離線均分確認／前景待送佇列；後端位於同一 repository 的 `apps/web`。手機與後端共用 `@travel-budget/contracts` API schema。這是程式實作狀態，不代表已部署或已通過真機驗收；模擬器驗收成果見 [archive](archive/README.md)，C 剩餘裝置項目見 [本機驗收](LOCAL_ACCEPTANCE.md#尚未完成的驗收)。

B3 已接新版帳本：新建依伺服器能力選擇固定基準、閱讀／新增／編輯／還款／設定皆採實際基準，JPY 可記到 0.01。B5d-1 起所有請求只走 v2，新操作保存 v2／單位及原 UUID；舊 v1 待處理紀錄不再查詢或重送，只提供明確捨棄，未 prepare 的離線紀錄可移回草稿重新確認，已完成結果仍可查看。下方恢復與凍結規則適用於 v2；非 TWD 離線只存草稿。非 TWD 建立開關仍關閉，待 B4 獨立核對後另依指示開放。持久化與相容細節集中在 [B3 架構](ARCHITECTURE.md#b3mobile-帳本與舊資料恢復)；下方 G2 的原 TWD 說明是遷移前能力，金額單位以 B3 規則為準。

- 登入頁提供建立帳號與忘記密碼。註冊成功回登入頁並帶入帳號，不自動登入；重設支援前導零六位碼、重新寄碼及已收到碼的直接輸入。四語提示新密碼至少六字元、最多 72 UTF-8 bytes，不 trim 密碼。
- E2 表單只留記憶體，離開清除密碼／碼並提醒；明確送出、防雙擊、429 秒數及錯誤／逾時提示。建立或重設結果不明時可先登入核對，不落盤或自動重送；匿名限流與帳務等待分開。密碼重設使舊手機 session 失效，本機草稿與待確認紀錄保留。E2 兩平台本機操作已驗，外部郵件投遞仍待驗，見本機驗收紀錄。
- 使用網站共用的帳號／密碼登入；access token 僅存記憶體，refresh token 與最後一次線上驗證的帳號身分，以同一筆資料存在按 API 環境隔離的 SecureStore。
- 重開 App 時更新憑證並恢復登入；登入過期／撤銷會清除私人快取。更新憑證採單一併發請求，每次 API 最多因 401 更新並重送一次。
- 更新後的 refresh token 若無法寫入 SecureStore，會清除不可再使用的舊憑證與私人快取，並嘗試撤銷新憑證；清除成功後回到登入頁，儲存空間仍無法清除時顯示錯誤並提供重試。舊登入恢復／登出結果不會覆蓋後續登入。
- 旅行列表顯示名稱、目的地、日期、個人分攤金額與狀態。旅行中優先，其次即將出發；個人封存旅行排最後。每頁 20 筆，支援載入更多與下拉更新。
- 旅行摘要顯示日期、角色、人數、支出筆數、本人分攤花費、應收／應付、今日全團花費及本人的總預算。金額皆為後端按旅行帳本基準計算的結果。
- 旅行空間使用「概覽／支出／結算」同層分頁，共用返回旅行列表與邀請入口。支出清單依日期、建立時間由新到舊，每頁 20 筆（游標分頁），支援載入更多與下拉更新（只重讀最新一頁）；每筆顯示日期、說明、付款人與帳本基準金額，外幣另顯示原幣金額（幣別代碼只標一次）；顯示捨入為零時不加負號。成員識別規則見下節，null 參照只顯示已移除，本人與已知虛擬標記保留。
- 單筆明細顯示分類、付款人、帳本基準金額、原幣金額／匯率與各成員帳本基準分攤；可讀 Web 已有的外幣、非均分、虛擬成員與歷史資料，金額沿用後端既有計算。附件內容與下載入口不在手機顯示。返回按鈕回到該旅行的支出清單，已有清單則沿用既有頁面。
- 結算顯示總支出、成員餘額（已扣除已登記還款）、建議轉帳（標示尚未付款，本人相關者優先）與既有還款紀錄；沒有支出、已全部結清與尚有欠款是三種不同狀態。
- 失去成員資格或資源不存在時，旅行摘要、支出與結算畫面顯示不可用並隱藏已快取的私人資料；之後重試遇到逾時、斷線或 5xx 也保持隱藏，直到成功讀取證明權限恢復。一般網路故障（沒有先前拒絕）仍可看到合法的舊資料。
- 支援載入、空資料、錯誤、重試與離線提示；回前景重新確認連線，前景／網路恢復時更新過期查詢，離線暫停的首次讀取可繼續。帳務查詢資料只保留於本次執行的記憶體；草稿必要的旅行名稱與成員選項另存最小本機快照。
- 四語系（繁中、簡中、英文、日文）、深淺色、安全區域、文字縮放、鍵盤表單與無障礙按鈕標籤；新增表單的單選／多選項目提供勾選狀態，欄位提供錯誤朗讀提示，Android 動態錯誤使用 polite 通知。
- U1a 共用元件已套入 U0c teal 深淺色、字級／間距／圓角；Action 支援 primary／secondary／ghost／danger、忙碌與停用，Chip 保留單複選語意並顯示勾選。Notice／Badge 區分說明、成功、警告與失敗；一般說明、自動保存及倒數安靜更新，失敗與需處理訊息以 polite 提醒（iOS 明確通知 VoiceOver）。TextField 提供聚焦輪廓、說明／錯誤、多行與金額樣式，保留 ref、原生鍵盤完成入口及 Android 行高。共用圖示採原生輪廓且不搶朗讀焦點；U2 核心頁資訊重排已實作，原生最大字級與閱讀器仍待獨立驗收；功能補齊見 ROADMAP G。
- 登出先撤銷伺服器 session，再刪除 SecureStore 及取消／清除私人查詢；重複點擊合併為一次登出。無法連線時保留登入並提示重試，不宣稱遠端已登出。
- 新增支出（旅行摘要與支出清單各有「新增支出」入口）：填寫說明（最多 200 字）、原幣金額（文字輸入、至多兩位小數，含 JPY；安全整數分，TWD／換算後上限 1,000,000,000）與完整精度匯率、日期（date-only，須是真實日曆日，有前一天／今天／後一天按鈕，不經 UTC 換算）、分類、付款人（預設本人，可不參與分攤）與分攤成員（預設全部成員）。按「預覽分攤」由後端依選擇的模式與固定成員順序分配，手機不計算金額（四模式見下方 G3b-1）；表單輸入一改，舊預覽立即失效並取消進行中的請求，晚到的舊回應不會覆蓋新輸入，改回原值也要重新預覽；重新預覽時先捨棄舊結果，確認只對應最新一次成功的預覽。預覽被拒（403／404，例如已被移出旅行）時，整個畫面只留下「找不到旅行」提示，不再顯示成員姓名、分攤或確認，之後的斷線或逾時也不會讓它重新出現，直到重新讀取成功。確認後以預覽的分攤原樣送出。離線時不能 HTTP 預覽或直接入帳，TWD 均分可另依 D3 規則確認並加入待送佇列；外幣及進階分攤只能保存草稿。
- 支出草稿（D1）：每個 API 環境／帳號／旅行保留一份 SQLite 草稿，保存原始說明、金額文字、日期、分類、付款人與分攤成員，未填完或暫時無效的輸入也可保存。畫面顯示保存中／已保存在此裝置／保存失敗，失敗可重試；只有落盤成功的輸入保證重啟恢復。離開／切背景會嘗試完成保存，回到新增入口可明確續填或捨棄；捨棄後的新草稿依最新已載入的成員選項初始化。換帳號隱藏原帳號草稿，同帳號回來仍可續填；線上新增入口重新進入須成功讀取旅行選項確認授權，已知撤權時隱藏私人內容。已開啟表單可斷網保存本機輸入；離線重啟由 D2 本機入口續填。
- 離線草稿入口（D2）：旅行列表可開啟「本機支出草稿」。線上讀過的旅行名稱與成功載入的成員／分類選項按環境／帳號／旅行保存在 SQLite，顯示選項最後更新時間；開啟旅行摘要時預載選項。只有旅行名稱、尚未保存選項的旅行會提示需連線。已保存選項的旅行可離線建立、續填或捨棄草稿，表單沿用 D1 的保存狀態，也可明確確認 D3 均分規則加入佇列；不持久化帳務查詢、預算、查詢快取或未確認預覽。
- 離線冷啟動：若恢復登入遇到斷線／逾時，且 SecureStore 有與憑證一起保存的帳號身分，可進入受限本機草稿模式；這不代表線上 session 有效，不能進入帳務頁或呼叫已認證 API。已知登入失效會清除身分並要求重新登入；舊格式憑證須先成功線上恢復一次才能提供本機入口。恢復連線不自動寫帳，使用者可恢復線上登入後到新增入口取得新預覽並確認，或按 D3 契約先明確確認均分規則加入佇列；未確認草稿仍不自動送出。斷線會清除開啟表單的舊預覽，不能恢復連線後直接沿用。
- D2 撤權：旅行摘要、成員選項、支出清單或結算讀取，以及預覽／C 提交查詢確認收到旅行 403／404 時，立即隱藏該旅行本機快照，保存不含私人名稱／選項的拒絕標記；原始草稿與待確認紀錄保留。拒絕標記落盤後重啟仍隱藏，只有新的成功成員選項讀取才解除；單筆支出不存在不視為整趟旅行撤權。快照保存失敗會提示，拒絕標記保存失敗時，本次執行仍隱藏並在讀取列表前重試，無法完成則顯示讀取失敗。
- 續填不恢復舊預覽：重新檢查金額／日期，預覽前刷新成員與分類；失效付款人／分類需重新選擇，失效分攤成員需明確移除，不靜默改動。使用者取得新預覽並確認後，在同一 SQLite 交易建立 C 的 UUID／凍結請求並標記草稿已交接；交易失敗不送 HTTP。交接後不能再續填或捨棄該草稿，結果不明只查詢或重試原 UUID；明確拒絕才原子恢復原始輸入，成功後舊草稿不得復活。
- 確認的當下凍結內容並產生一個 UUID，防止雙擊重複送出；401 自動更新憑證後的重送、手動重試與結果查詢一律沿用同一個 UUID 與內容。只有伺服器明確回成功才顯示「已儲存」，之後清單、明細、旅行摘要與結算會失效並重讀；重讀失敗只顯示更新失敗與重新整理，不要求重新記帳。儲存後可查看明細、再新增或返回該旅行的支出清單；清單已在導覽堆疊中時返回既有清單。伺服器在寫入前明確拒絕（400 等）時回到編輯，修正後是新的提交。
- 待確認紀錄：送出前先把環境、帳號、旅行、UUID、凍結內容與狀態存入裝置的 SQLite（`expo-sqlite`，不存 token，獨立於可清除的查詢快取），存不進去就不送出。逾時、斷線、5xx、回應遺失或帳號／旅行權限問題都不會清除紀錄；畫面顯示「尚未確認的支出」，只能「查詢結果」或「以原內容重試」（同一個 UUID，後端冪等，不會重複記帳），確認前該旅行不能新增其他支出。App 啟動、回前景與恢復連線時自動以同帳號查詢結果，找到就移除紀錄並更新各畫面；非佇列 C 紀錄只查詢，D3 佇列可依明確確認的規則安全重試。登出或換帳號後，其他帳號看不到也送不出前一個帳號的紀錄，同帳號回來可繼續；無法再存取旅行時保留紀錄並提示無法確認，不假稱失敗；409 會查明原請求，不換 UUID。離開畫面不會取消或清除已送出的請求。Web 預覽沒有登入也沒有 SQLite。

- D3 待送佇列：線上與本機草稿表單均提供「確認均分規則並加入待送佇列」，明示後端決定各人金額與尾差。每次確認原子保存均分意圖／UUID 並清除來源草稿，可離線確認多筆；未送出項目可捨棄或移回草稿重新確認，若已有草稿須另外明確確認是否替換。旅行列表／本機入口有佇列畫面，顯示等待、需處理、已凍結／結果待確認、冷卻時間及失敗提示；已凍結項目不能修改或捨棄。
- D3 前景同步：只在前景、連線且登入有效時依序送出明確確認的項目，啟動、回前景、恢復連線與前景每 30 秒檢查。先重新授權並核對完整成員順序／原欄位，再取後端均分預覽、原子接回 C；名單／順序異動停止並保留原輸入供重新確認。準備後重啟、丟回應或 5xx 只查原請求／重試同 UUID 與內容；429 的等待落盤，登入失效／撤權不刪資料，換帳號看不到也送不出原帳號項目。409 查回不同內容時保留已查明的衝突提示，不自動另建支出。詳細邊界見 [D3 契約](BACKEND_CONTRACT.md#d3-離線確認與分攤契約)。

- E1 旅行入口：旅行列表（含空狀態）可線上建立或加入；名稱 1–100 字、說明最多 2,000 字，日期可空且必須是真實 date-only／正確順序。加入接受 6–10 碼英數邀請碼或目前環境 Web origin 的 `/join/{code}`；按鈕即參加確認，已加入者直接回原旅行。建立者為 admin，新加入者為 member。
- E1 已確認操作：先保存 UUID／凍結內容再送 HTTP，失敗零送出。獨立 SQLite 操作表按環境／帳號隔離，結果不明不能改內容／UUID 或捨棄；旅行列表「待確認操作」提供查詢與明確原內容重試。啟動／回前景／恢復連線只查結果，不自動重送。成功／終局拒絕清除凍結 payload（含邀請碼），保留最小結案提示供開啟旅行或移除；429 沿用 C／D 帳號期限，重啟不清除。成功後讀最新 landing／options，receipt 不作為離線授權快照。
- E1 邀請：目前成員從摘要明確開啟邀請頁取得碼與網站連結，可複製／系統分享。畫面提醒持有連結者可加入；碼只留邀請頁記憶體，登入切換、離開、背景或撤權即隱藏，不進一般 query 或快照。Universal Links／App Links 留 F。E1 兩平台本機操作與故障矩陣已驗，真機與完整閱讀器另列 F。

U1b 提供「旅行／記一筆／我的」全域列；旅行與我的保留分頁狀態，記一筆先選旅行，線上沿用現有旅行分頁、離線只列有成員選項的本機旅行，並進既有草稿／pending 守衛。我的顯示帳號／名稱、登出與本機記帳；旅行列表也可進本機入口，分開草稿、待送佇列與 E 待確認操作，讀取失敗不畫零筆。表單與明細放在分頁外，採共用安全區域、頁首與鍵盤容器，保留既有離開提醒；旅行名稱可捲動，撤權立即隱藏私人內容。原 URL 保留、交易引擎仍在根 provider；原生裝置驗收由其他人執行。

U1c 旅行列表將建立／加入合為一列，保留本機入口及未結案佇列／E 待確認數量；本機讀取中或失敗不畫零筆。卡片依狀態、完整名稱、日期／人數、本人分攤／應收付排列；封存與旅行階段只使用後端欄位，零餘額不宣稱結清。概覽先顯示本人帳務與新增支出，再放今日團費、日期、人數、預算、筆數／角色；目的地／說明可展開。未設預算與實際零預算分開，缺少任一日期端點明確標示；金額依實際容器寬度與字級轉單欄，不用整個視窗推估卡片空間。保留 FlatList 分頁／下拉更新與原操作 IDs，catalog 或 HTTP 撤權時隱藏快取；不逐卡查 landing，也不預抓邀請碼。金額／日期已沿用 U2a 共用顯示格式；iOS 長名稱／最大字級及同資料 Web 對照仍待獨立驗收。

U2a 支出列表依說明、語系日期、分類／付款人、本幣金額、原幣資訊排列；明細以本幣金額與每人原始份額分層，保留外幣代碼／原額／匯率。用 ID 標示本人，同名者附最短足以區分目前可見成員的穩定 ID 後綴；已無法解析的參照顯示「已移除成員」。後端可選 `payerIsVirtual`／分攤 `isVirtual` 明示虛擬成員，舊回應缺欄位時不猜身分；不代表查詢目前是否仍在旅行。編輯為一般操作、刪除為危險操作，仍進 E3 的原版本／確認／UUID 流程。列表維持游標、下拉更新與 pending 入口，catalog／HTTP 撤權立即遮蔽內容，搜尋入口見下節 G4b；附件仍另排。

`i18n/format.ts` 統一顯示精選幣別符號（NT$／¥／$／€／HK$／฿）、未知碼及至多兩位小數，JPY 也保留分角；負號在符號前、整數不補零。日期四語依 U0c 顯示，date-only 直接讀年月日，沒有時區轉換；旅行卡片／概覽與支出閱讀共用 `useDisplayFormat`。原始輸入、後端到分／分攤與資料保存不變。共用返回控制靠左、內容寬度且保留至少 48 觸控高度。新增／編輯表單與結果頁已套入下方 U2b；iOS 實際畫面驗收由其他人執行，Android 延後。

U2b 新增與本機草稿以金額 → 多行說明／分類 → 日期／付款人 → 分攤 → 預覽／確認排列，金額套共用 amount 樣式，原始文字與 date-only 輸入不改。旅行頁首保留；保存中／已保存是安靜短列且明示尚未入帳，一般記帳／草稿說明可展開，保存／捨棄失敗、失效成員及離線均分規則仍完整顯示。線上主動作由預覽轉確認，預覽卡核對總額、說明、日期、分類、付款人與每份分攤；離線確認分區保留獨立授權文案與原佇列入口。

編輯先顯示唯讀原金額，預設基本資料保留原幣／付款人／份額；明確切換重新分攤才有金額欄與完整付款人／分攤選擇。基本模式按「核對變更」，重算模式按「預覽分攤」，之後才明確確認；衝突、新舊份額、刪除警示與失敗不藏入說明。iOS 新增／均分金額皆有 decimal-pad 完成列，說明 Next 到日期，日期 Done 收鍵盤；原 TextField 行高／表單鍵盤容器保留。結果頁突出已入帳金額及完整份額，刷新失敗仍是已成功，只重讀、不重記。未改 C／D／E 引擎、API、附件／標籤／行程保存與 UUID／429 規則。

Web 匯出只提供介面預覽，登入明確停用；不把憑證降級存到 localStorage。原有網站仍是完整 Web 用戶端。

尚未提供行程編輯、附件、OS 背景同步、推播或帳號刪除。原始草稿不自動確認或入帳；D3 只同步使用者明確確認的均分意圖，實作不代表裝置驗收通過。API 與確認契約見 [後端契約](BACKEND_CONTRACT.md)。

已有 API client／session 行為測試與 CI。App ID、簽章、EAS、商店資訊及正式圖示尚未設定。原生打包匯出不等於原生編譯；已有 Maestro 模擬器核心流程；iOS／Android 完整真機驗收仍待完成，見 [本機驗收](LOCAL_ACCEPTANCE.md)。

### 成員識別

支出列表／明細、新增／編輯／成功結果與結算／還款共用名冊標籤索引：目前名冊的唯一姓名不加碼；同名從 ID 末 6 碼開始，碰撞時延長至足以區分，依整份名冊決定，不依已載入的支出頁面。目前成員沿用名冊現名，因此舊支出也顯示改名後的姓名，即使支出回傳不同姓名仍以目前名冊為準；保留「你」與虛擬旗標；目前名冊有旗標時優先於歷史 DTO，已認領的真人不沿用舊虛擬標記。`id === null` 只顯示已移除，不讀取舊姓名。畫面與無障礙標籤沿用同一文字，避免一般姓名帶入完整 ID。

名冊尚未載入、離線沒有快取或一般讀取失敗而無可用名冊時，只顯示參照姓名及已知標記，不推斷歷史資格、不加碼；這段期間不保證同名消歧。成功讀到名冊（包括空名冊）後，有 ID 但不在名冊的歷史參照一律帶短碼；同一份畫面資料內，與其他同名歷史參照／目前同名短碼碰撞時採共用延長規則。目前名冊不是完整歷史名冊，因此不保證歷史短碼跨畫面／分頁永遠相同。不得把此限制改寫為所有歷史身分已完整對齊。

名冊在畫面上層共用按環境／帳號／旅行隔離的 expense-options Query，標籤 observer 不因掛載再刷新，列與標籤不呼叫查詢。TripChrome／既有表單仍負責重新核對；冷進明細可讀取缺少的名冊。支出清單的下拉更新／空清單更新／錯誤重試一起重讀支出最新一頁與名冊，離線不發起更新；catalog 已隱藏旅行時，這些一般更新不重讀名冊。撤權後隱藏快取與私人帳務，顯示不可用提示；仍可明確按名冊重試來重新核對授權，沿用既有授權與保存流程，不直接解除 catalog blocked。新增／編輯及還款建立沿用自身已核對的 options／context，還款撤銷共用名冊快取；原／最新衝突資料各持有索引。VoiceOver 實際朗讀方式仍待原生驗收。

## G1a 旅行資料與個人封存

旅行概覽的「旅行設定」提供最新資料讀取、管理員編輯名稱／說明／目的地／date-only 起訖日，以及所有成員可用的個人封存／取消封存。封存只改本人列表排序，不隱藏全團、不停用記帳、不修改成員資格。未確認輸入只留當次畫面；輸入有變更時不能先封存而把資料丟掉，離開有提醒。

目的地保留 Web 的完整地點物件。首片提供名稱、完整地址、真實緯經度及明確清除；一般資料編輯不送目的地，不清掉座標、國家或語系名稱。座標改變時不沿用舊國家資料，名稱更正會移除舊翻譯。地點搜尋／自動補全尚未接入；不填虛構座標，不在 App 直接複製第三方搜尋。

核對前重讀最新 context，旅行資料及本人封存使用獨立 revision。Web 同時修改或被降為一般成員時保留輸入、顯示最新資料；明確核對後只套用原本實際修改的欄位，其餘沿用最新內容，再確認送出。確認後沿用 E SQLite 操作：固定 UUID、先保存再送、同旅行 C／D／E 互斥、帳號／環境隔離及共用 429 等待；重啟只查結果。終局拒絕可由「待確認操作」保留原變更重新開啟；結果不明不能另建 UUID 重做。被降權仍是成員時，拒絕結果可查詢，不把旅行藏起來；被移除則沿用 catalog 撤權保護。

成功後刷新列表／摘要／帳務查詢及本機旅行名稱／成員快照；重讀失敗仍保留提交成功，提供只讀重試。旅行日期修改與 Web 共用相片自動關聯重綁交易，不改手動關聯。成員列表／虛擬管理與 G1c 見下節；iOS 畫面、字級與故障操作由其他人驗收，Android 延後。

## G1b 成員列表與虛擬成員

旅行概覽的「旅行成員」列出全名冊、本人／虛擬標記、角色與加入時間；一般成員可閱讀，只有管理員可新增或更名虛擬成員。名稱去除首尾空白後為 1–200 字，重名可使用，依共用名冊短碼區分；不修改真人帳號名稱、不提供登入資料。更名保留 ID、加入時間、角色及所有支出／分攤／還款參照。名稱屬於該虛擬身分，全旅行及歷史參照重讀後反映現名，並非逐筆修改舊帳。

線上核對最新全名冊後才顯示確認；名冊、角色或虛擬身分被認領／移除時要求核對最新內容，不自動換版本送出。未確認名稱只留本頁，取消及離開提醒沿用表單；確認後沿用 E 固定 UUID／SQLite／同旅行協調、登入／環境隔離及共用 429 等待。重啟只查原結果；結果不明凍結表單，終局拒絕才可保留原輸入重開。成功後刷新帳務及本機名冊，讀取失敗只讀重試，不重複建立。

新增／編輯支出、支出列表／明細、結算餘額／建議／歷史還款及還款登記／撤銷共用旗標與上層標籤索引，不逐列查詢。成員選項及結算旗標為可選，舊快取／舊回應繼續相容；public 結算不擴充身分旗標。後續管理見 G1c。開發檢查與 iOS（iPhone／iPad）待驗見 [G1b 交接](LOCAL_ACCEPTANCE.md#g1b-成員與虛擬成員交接)，Android 延後。

## G1c 角色、退出與刪除

名冊的「成員與旅行管理」提供管理員變更其他成員角色、移除成員及刪除旅行，所有成員可退出。不能改自己的角色或以移除代替退出；最後一位真人管理員需先指定另一位真人管理員，或刪除旅行，只有虛擬管理員不算可接管者。移除／退出保留支出、分攤、還款、User 及歷史作者；清理該成員的待辦指派／完成名單與通知。旅行刪除會清理全旅行帳務、行程、待辦、留言與相簿，個人飛行／住宿記錄只解除旅行連結，檔案由既有延後清理工作處理。

管理動作先重讀最新內容，顯示對象、角色或危險操作說明，再明確確認。名冊或待刪資料變動需重新選擇／確認；未確認操作不落盤。確認後沿用原 UUID／SQLite、同旅行協調及共用 429；退出／刪除成功會隱藏本機旅行入口，最小 receipt 與持久隱藏標記一起提交。回應不明只能查原結果；隱藏後不重送寫入、不開舊旅行。未有 receipt 的不明結果維持待確認，不能憑旅行消失推論成功。

虛擬轉真人採現有 Web 認領連結：管理員在手機複製或系統分享，對方在 Web 自行註冊／登入。連結是可認領的能力，只提供給指定成員；撤換旅行分享碼會讓舊連結失效。沿用既有共用身分交易及帳務遷移，手機不建立對方憑證表單、不保存密碼。完成後手動刷新名冊及帳務即可讀到真人。原生認領表單與手機接收認領 deep link 未實作；驗證與 iOS 待驗見 [G1c 交接](LOCAL_ACCEPTANCE.md#g1c-權限與危險操作交接)。

## E3 編輯與刪除支出

明細提供線上編輯／刪除。預設只改基本資料，保留外幣、非均分與其他未支援欄位；後端允許時可明確選「重新分攤」，選擇四種模式並核對付款人、新舊金額與份額；缺進階能力仍沿舊均分路徑。未知歷史分類保留，無變更不送出。刪除需先看最新說明／日期／付款人／金額與不可還原警示，再確認。

確認前後的版本與 UUID 保護防止覆蓋新內容；衝突保留輸入，顯示最新內容並要求明確重載／核對。已確認操作先保存，回應不明可從「待確認操作」查詢或原內容重試；確定拒絕可明確保留輸入重開，只有新確認才產生新 UUID。成功後重讀帳務，資料更新失敗只重讀。未確認表單離開會提醒，不新增離線編輯草稿；D 新增草稿仍獨立。契約見 [E3](BACKEND_CONTRACT.md#e3-支出維護)，審查與兩平台本機操作／故障矩陣已通過，真機與完整閱讀器另列 F。

## E4 還款

結算建議列可「登記已付款」，也可手動記錄；預填後仍可調整付款／收款人、TWD 金額與備註，確認畫面依 ID 區分同名成員。支援部分、超額及沒有建議的實際付款，偏離建議會提示，App 明示不執行轉帳。還款歷史可確認後撤銷誤登，並由後端重算。

開表單及確認前讀最新結算／成員；狀態或 payment 變動時保留原輸入、顯示最新狀態並要求再次確認。確認先落盤固定 UUID，丟回應／當機只查原結果，成功後更新列表、摘要及結算；讀取失敗不要求再登記。待確認操作涵蓋 E4 的查詢／原內容重試、確定拒絕的保留輸入重開。未確認不保存離線草稿，既有 D 行為保留。契約見 [E4](BACKEND_CONTRACT.md#e4-登記與撤銷還款)；獨立審查與兩平台本機操作／故障矩陣已完成，真機與完整閱讀器仍待驗，結果見 [交接文件](LOCAL_ACCEPTANCE.md#e4-還款驗收交接)。

## U2c 結算與還款顯示

結算先呈現本人應收／應付，再顯示後端狀態、本人優先的建議、已登記還款、全員餘額與總支出。沒有本人餘額不補假零，沒有建議不等於結清；零餘額與無支出仍沿用後端三種狀態。四語金額與裝置時區的還款日期使用共用格式；同名、本人及已移除參照使用穩定 ID 區分。catalog／HTTP 撤權與登出隱藏快取和操作。

手動還款依付款人／收款人／金額／多行備註排列，參考結算可展開；確認逐項核對方向、金額及備註，部分／超額／無建議的提示仍可見。撤銷顯示完整原紀錄與危險確認，不執行退款。iOS 金額鍵盤有 48 觸控高度的完成列，Android 保留完成入口；原始輸入、E4 最新狀態確認、固定 UUID、409／429／結果不明與成功後只讀更新流程不變。G1b 已擴充結算／還款與選項的可選虛擬旗標，仍按有效 ID 操作、不以名稱猜測；舊回應缺旗標仍相容。[U2c 交接](LOCAL_ACCEPTANCE.md#u2c-結算與還款驗收交接)列出回歸及待其他人執行的 iOS 操作，Android 延後。

## U2d 帳號與旅行表單顯示

登入以單一任務標題、共用 Card／TextField 與鍵盤表單容器顯示，保留帳號／密碼自動填入及安全輸入；登入為主操作、建立帳號為次操作、忘記密碼為文字操作。註冊／重設沿用共用表單，密碼規則附在密碼欄；重設確認階段明示「重設密碼」，iOS 驗證碼鍵盤的「下一欄」只移至新密碼，不提交。寄碼與驗碼等待仍各自判斷且不重設期限，密碼／驗證碼不保存、離開清除及成功回登入沿用 E2。

建立／加入旅行使用一般說明、完整錯誤與一致提交位置；多行旅行說明 Next 到開始日期，結束日期 Done 收鍵盤，date-only／原始文字不改。邀請頁以旅行上下文與返回旅行摘要標示目的地，明確標籤區分邀請碼／連結，複製為主操作、分享為次操作、刷新置後，失敗與複製成功分開提示。只在明確開啟時取得，背景／換帳號／撤權仍隱藏內容；未確認表單提醒、E1 UUID／恢復與既有授權不變。回歸與 iOS 待驗見 [U2d 交接](LOCAL_ACCEPTANCE.md#u2d-帳號與旅行表單驗收交接)，Android 延後；U2e 狀態顯示見下節。

## U2e 本機與恢復顯示

本機旅行、待送佇列、E 待確認操作及 C 待確認支出使用共用狀態卡與頁首。空列表、載入、讀取失敗、已確認待送、需重新確認、結果不明與確定完成／拒絕分開；讀取失敗不顯示成零筆，過期登入與離線維持明確提示。本機選項更新時間及等待期限使用四語、裝置時區顯示，支出日期仍按 date-only 顯示。

等待時間直接讀取 C／D／E 共用 SQLite 帳號／環境期限；僅顯示有效等待（終局佇列不顯示列內期限），到期自動重畫；未到期時停用線上查詢／重試／同步，不重新起算，也不新增持久化來源。未凍結的佇列才可移回草稿／危險捨棄，替換現有草稿需另一個明確操作；已凍結只走原內容恢復，確定完成才可移除 E 提示，確定拒絕才提供既有保留輸入重開。入口待處理數與清單共用帳號／環境及 catalog 可見性，終局提示不算待處理；雙擊合併、帳號／環境核對及 catalog 撤權隱藏私人卡片，晚到恢復不跳入已撤權旅行；交易引擎、UUID 與 HTTP 契約不變。[U2e 交接](LOCAL_ACCEPTANCE.md#u2e-本機與恢復驗收交接)列出回歸與 iOS 待驗，Android 延後。

## G2a 旅行幣別與匯率

旅行設定可進入「旅行幣別與匯率」。一般成員唯讀，管理員可按 ISO 代碼搜尋並加入最多 30 個常用幣別、選新增預設幣別及設定各幣別自訂匯率；移除預設外幣時回到 TWD。TWD 固定 1，外幣留空代表使用參考匯率，不會假設缺值為 1；數字不依顯示精度回寫。設定沿用 Web 的同一份旅行資料，只影響之後表單預填，不改寫舊支出的原幣、歷史匯率、TWD 或分攤，也不改已確認請求。

參考匯率須明確按鈕讀取，顯示既有 Frankfurter 每日發布值、各幣別發布日期及來源，不標為即時報價。讀取失敗保留輸入，可重試或填手動匯率；讀取結果不覆蓋自訂輸入。旅行常用幣別的參考值／日期／來源在共用唯讀區顯示；所有人可讀，只有管理員可修改旅行設定。

未確認輸入僅保留在畫面；離線／背景清除確認並使進行中的核對失效，核對世代自點擊起涵蓋 SQLite／HTTP 等待與 transport 守衛，晚到結果不因恢復連線／前景而重建確認。429 若落盤失敗，保留原絕對期限並在下次請求前重試保存；保存成功前不發起新請求，重試不延長等待。重新讀取設定與權限後才可確認，衝突提供最新值、保留輸入或捨棄；確認後使用 E 的 SQLite／原 UUID 恢復與帳號限速。不明結果鎖定表單、轉待確認操作；管理權降級不當成旅行成員撤權。外幣新增／草稿見 G2b，編輯見 G2c；D 佇列維持 TWD 均分。

## G2b 外幣新增與草稿

新增表單沿用常用幣別，並補 TWD、預設／草稿原幣；未設定退回 TWD。只有新草稿讀旅行預設與自訂匯率，恢復草稿不套最新設定；切換幣別保留金額原始字串，改用該幣別自訂匯率，缺值留空。使用者明確讀取每日 Frankfurter 參考值、核對發布日期後才能套用，讀取不覆蓋手動值；無報價／503 保留輸入，不默認 1。匯率方向為 1 原幣 = ? TWD，輸入及確認保留完整精度；極小／大值可用指數文字表示。

預覽前重讀成員，原幣／匯率／TWD 與每份 TWD 都由同一後端 computeSplits 決定。原幣到分，JPY 不另取整；很小的有效換算可能依 Web 規則取整為 TWD 0，確認仍明示總額及零份額。所有輸入修改取消預覽，確認內容及恢復比對包含原幣與完整匯率。C 保存原 UUID／固定 body，重啟先查原結果，不跟隨之後設定／參考值；待確認、結果及明細均顯示原幣／匯率。

SQLite schema 8 不加表：草稿可選原幣／匯率文字與來源／日期，舊缺欄位原樣作 TWD／1；舊 pending 不重寫。外幣可離線續填保存，不能進入 D TWD 佇列；UI、引擎、SQLite 入列／prepare 及同步均保護這個邊界。表單讀取的 429 共用持久帳號等待，背景／斷線／換帳號／撤權檢查一路到 transport；裝置驗收另交 iPhone／iPad，外幣編輯見 G2c。

## G2c 外幣均分支出編輯

以下保留舊後端的均分編輯相容路徑；支援新能力時採用下節 G3b-2 的明確重新分攤。

編輯預設只改說明／分類／日期，歷史原額、幣別、精確匯率、付款人及分攤原樣保留，附件／標籤／行程亦不清除。可重算的支出由後端判定：有效現任成員、完整合法原額／幣別／匯率／TWD 資料，而且逐人份額與 Web 固定順序的原幣均分結果完全一致。資料庫未保存原分攤模式，只能依現有數值判定；不同尾差落點、非均分、缺欄位或失效成員保持基本編輯，進階維護留 G3／Web。

使用者明確選「重新均分」才開放原額、幣別、匯率與成員。初始匯率取自此筆帳務，不採旅程最新設定；切換幣別保留輸入數字，新幣別可讀旅程自訂預填，切回原幣恢復歷史匯率，沒有匯率須手動填入，TWD 固定 1。編輯不自動讀取或套用每日參考值。後端預覽及確認顯示新舊原幣、完整匯率、TWD 金額與份額；改輸入／模式／離線使確認失效，晚到預覽不能復活。

Web／成員改動須核對最新內容再預覽；保留相對舊基準的明確編輯；原額／幣別／匯率視為一組，任一實質修改就保留整組，避免把原額套入他人幣別；整組未改才採最新值，純格式變更不算修改。其他未改的資料取最新內容。最新帳務不再可均分時回到基本模式。未確認表單不增加離線保存；確認後沿用 E 的 SQLite／原 UUID、原內容重試、receipt、共用帳號等待及撤權。舊 TWD body／receipt 指紋與 schema 8 不重寫；裝置操作交接見 [G2c](LOCAL_ACCEPTANCE.md#g2c-外幣編輯交接)。

## G3b-1 進階新增與草稿

新增與本機草稿共用四語分攤欄位：均分、固定原幣金額、百分比、份數。逐人文字按成員 ID 與模式分別保存；切模式、取消／重選成員不混用或清除其他模式的文字。留空與 0 不同，欄位提示精度、範圍及留空規則；嚴格解析完整文字後才傳 number／null，平衡、換算與尾差由後端決定。預覽列出模式、原幣／基準總額與逐人份額，改任一輸入、斷線或晚到回應均不能沿用舊確認。

須同時有目前模式的預覽與新增能力才可送出進階請求；能力不足仍可續填草稿，不降級均分。舊草稿缺模式視為均分，缺能力的後端沿用舊均分 body。進階確認按預覽回傳的成員 ID 重排 values，完整模式／輸入／份額交 C 凍結，原 UUID 恢復、帳號隔離與共用限速不變。D 只接受 TWD 基準＋TWD 原幣＋均分，畫面、引擎、SQLite 入列／prepare 及同步都拒絕非均分，包括結果剛好相等者。

實作與回歸已完成，獨立審查及裝置驗收未完成；進階編輯見下節 G3b-2，非 TWD 建立開關不變。操作驗收集中在 [G3b-1 交接](LOCAL_ACCEPTANCE.md#g3b-1-進階新增與草稿交接)。

## G3b-2 進階支出編輯

編輯預設基本資料，只送出有修改的說明／分類／日期，歷史帳務不重算。支援 `splitModes` 及同模式預覽能力時，可明確選「重新分攤」，再選均分／固定原幣金額／百分比／份數；不預選歷史模式、不反推原始比例，也不從歷史份額預填固定金額。共用 G3b-1 的四語逐人欄位，切模式保留各模式文字。未知或已移除的歷史成員會阻擋重算，須明確移除其選取並選目前成員；失效付款人須重新選擇。舊後端仍沿原均分能力與 body，不將進階輸入降級。

預覽前後重讀 revision、名冊與能力；確認顯示模式、新舊原幣總額／完整匯率／基準總額、舊基準份額與新原幣／基準份額。歷史原幣逐人份額未保存，不以逆算假稱原值。模式、逐人文字、成員或其他欄位改動、離線與背景使確認失效；確認等待本機守衛時也檢查輸入世代。

衝突需明確核對最新內容再預覽。進階重算保留使用者選擇的完整帳務輸入（原額／幣別／匯率／付款人／成員／模式／逐人文字），避免把固定金額解讀成他人剛改的新幣別；未改基本欄位採最新值。能力消失保留輸入並阻擋確認，可切回基本編輯，不默默轉均分。確認後 E 凍結 mode、按確認份額 ID 對齊的 values、revision 與 UUID；重啟只查原結果，手動原內容重試。終局拒絕可從該筆 frozen body 重開核對，不自動送出，也可回基本模式；未確認編輯仍僅保留畫面內。

自動化驗證與裝置待驗集中在 [G3b-2 交接](LOCAL_ACCEPTANCE.md#g3b-2-進階編輯交接)。本片不改後端、持久化 schema、D 佇列或非 TWD 建立開關。

## G4a 個人預算

旅行概覽提供「我的預算」入口，顯示本人總額與分類預算、已入帳分攤花費、剩餘或超支。後端在同一授權快照讀完整旅行支出，使用 Web 的 `computeBudgetProgress`；不把已載入的一頁當全量，不納入還款、未送出草稿或佇列。分類進度保留未知歷史分類名稱；沒有設定與零花費分開呈現。進度是上次讀取的結果，可手動刷新，不宣稱即時推播。

本人可在線上設定總額及七種分類，各自獨立、不要求分類合計等於總額。使用旅程基準幣（包含既有非 TWD 帳本），金額最多兩位小數、每欄上限 1,000,000,000；空白或 0 取消該項，全部清空取消預算。清空只改欄位，仍須核對新舊設定並確認；不載入舊的共用 legacy budget 作為個人設定。四語、可縮放文字與 iOS 數字鍵盤完成列沿共用元件。

Web／Mobile 共用本人預算 revision、正規化與交易寫入；其他成員改自己的預算不衝突。同一人並行修改需核對最新內容，僅保留本次實際改過的欄位，再次確認。確認後沿 E 保存原 UUID／完整 body，回應不明或重啟只查原 receipt，手動重試保持原內容；終局拒絕可重開，未確認表單不落盤。共用帳號限速、同旅行互斥與撤權守衛不變。API 不接受指定其他使用者，預算內容不出現在 receipt 或其他成員／public DTO。

程式驗證與裝置待驗見 [G4a 交接](LOCAL_ACCEPTANCE.md#g4a-個人預算交接)。G4b 搜尋／篩選／分析見下節；非 TWD 新建開關仍另列。

## G4b 搜尋、篩選與分析

支出清單的「搜尋與分析」讀取整趟旅行已入帳支出；關鍵字比對描述／付款人名稱（忽略大小寫、字面比對），可組合分類、付款人 ID 及含起訖日的日期範圍。先修改條件，再按套用；結果標示實際套用條件，清除會回第一頁。付款人選項來自全旅行歷史參照，同名使用 ID 後綴、本人與虛擬成員另標示；無法解析的參照合併為已移除成員，不猜姓名。未知歷史分類沿原手機 DTO 歸入「其他」。

每次讀取同時回全量符合條件的筆數、全團基準幣合計、本人分攤、分類合計及成員付款／分攤；分析沿 Web 計算及歷史分攤正規化，與載入頁數無關。不包含還款、草稿、佇列、私人預算、收據或標籤；不是跨旅行分析。每頁 20 筆，資料異動使下一頁拒絕合併，需刷新第一頁；由明細返回也刷新已套用的條件。

查詢條件與結果只留目前畫面，無新增本機資料表或搜尋歷史。新條件取消舊請求，SQLite 等待、refresh 重播、背景／離線、換帳號／環境及共用 429 沿現有讀取守衛；授權拒絕清除結果，暫時網路失敗可保留同條件上次結果並顯示錯誤。四語／鍵盤／最大字級及閱讀器的裝置驗收仍待補，見 [G4b 交接](LOCAL_ACCEPTANCE.md#g4b-搜尋與分析交接)。

## G5 語言與外觀偏好

登入頁與「我的」均可開啟語言／外觀設定。語言可選繁體中文、簡體中文、英文、日文或跟隨系統；外觀可選淺色、深色或跟隨系統，預設皆跟隨系統。選擇保存成功才套用到全域文字、日期格式、語意色彩、導覽與狀態列；不重建登入、草稿或待確認引擎。系統模式沿 Expo locale／React Native appearance 訂閱，日文 `ja` 映射 `jp`，不支援的系統語言使用英文；手動選擇不隨系統變動。

偏好屬於本 App 容器的裝置設定，登出、換帳號或 API 環境後保留，不同步到 Web 帳號或其他裝置。重啟讀回；讀取失敗或資料格式不支援時先用系統設定，可重試或明確重設兩項偏好；保存失敗保留原設定並提示。重設不刪帳號、草稿、佇列或憑證。Web 預覽僅以本 origin 的 localStorage 保存這兩項非敏感偏好。

「關於」版本直接讀 Mobile package；網站按鈕開啟本環境已設定的 Web origin（未另設則採 API origin），不附 token、帳號或私人路徑，開啟失敗可重試。現有 repository 沒有客服／隱私頁，正式支援入口仍留 F4，不以網站首頁宣稱已完成。裝置、最大字級與閱讀器待驗見 [G5 交接](LOCAL_ACCEPTANCE.md#g5-語言與外觀交接)。
