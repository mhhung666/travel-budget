# Mobile 現有功能

本頁按使用者在 iOS／Android App 中的操作整理。Web／PWA 與 App 的能力差異見 [跨端產品設計](../../../docs/design/README.md)。待開發項目依 [路線](ROADMAP.md) 排序，模擬器、真機、閱讀器與外部服務的實測範圍見 [本機驗收](LOCAL_ACCEPTANCE.md)。

## 帳號與我的

- **登入、註冊、重設。** 用帳號與密碼登入。註冊成功後回登入頁並帶入帳號；忘記密碼可寄送、重寄或輸入已收到的六位數 Email 驗證碼，保留前導零。修改或重設密碼後，舊 session 需重新驗證。
- **個人資料。** 「我的」提供顯示名稱、頭像裁切／上傳／移除、密碼與驗證新 Email。未確認密碼、Email 驗證碼只留畫面記憶體。結果未知時依該流程讀回現況，重新進入不自動重寄。登出或換帳號後隔離私人快取與本機工作。[帳號服務與錯誤處理](BACKEND_CONTRACT.md#m1-本人資料)
- **通知與好友。** 帳號層偏好可設定 Email 通知及通知語言，同步 Web。「好友」可接受、拒絕、收回邀請及移除關係；從旅行名冊邀請其他真人。原生收件匣、推播與刪帳的狀態見 [路線](ROADMAP.md)。

### G5 語言與外觀偏好

裝置可跟隨系統或指定繁中、簡中、英文、日文與深淺色。偏好跨登出保留，與帳號層通知語言分開。表單支援原生鍵盤、安全區、大字級、狀態與錯誤朗讀。Expo 的瀏覽器匯出可預覽畫面，登入及原生資料庫操作須在 iOS／Android 執行。[裝置偏好](ARCHITECTURE.md#g5-裝置偏好)

## 旅行首頁與快捷記帳

### T2 旅行首頁與個人封存

旅行列表分一般／已封存，旅行中與即將出發置頂，其餘依年份或未排日期分組。依全量計數分頁，支援下拉與載入更多。卡片顯示本人分攤與待收付；主區開概覽，更多提供個人封存／還原。封存只改本人列表，還原最後一筆仍留在原空分頁。[旅行卡與快捷規格](../../../docs/design/MY_TRIPS.md)

### T3a 記一筆候選

全域「記一筆」從尚未封存的授權旅行中選擇，按記帳情境排序並分頁。旅行內的明確入口使用目前旅行；離線只能從本機可用的選項明確點選。[候選來源](ARCHITECTURE.md#t3a-候選與最小本機狀態)

### T3b 快捷選擇與切換

線上確認全量資料中只有一趟進行中，或沒有進行中且只有一趟可用旅行時，直接進新增表單。上次使用只影響候選排序。切換旅行時先保存原旅行草稿，保存失敗保留原表單；未解決的送出或撤權依原操作處理。[切換規則](ARCHITECTURE.md#t3b-選擇偏好與草稿切換)

## 建立、加入與管理旅行

- **旅行。** 建立時在名稱下搜尋帳本基準幣別；選項來自後端，建立後固定。加入可使用邀請碼，旅行內提供複製／系統分享。線上確認後若回應遺失，回到待處理操作查原結果。[建立與恢復](../../../docs/design/BASE_CURRENCY_CREATION.md)
- **設定。** 管理員可改旅行資料、起訖日期及目的地，調整記帳預設幣別、常用幣別及自訂匯率。成員可讀設定並封存自己的旅行。
- **名冊。** 可讀成員與角色。管理員可新增／更名虛擬成員、分享認領連結，由對方在 Web 完成認領。角色變更、移除、退出與刪除須核對影響；最後一位真人管理員退出前須先交接或刪除旅行。[權限與危險操作](BACKEND_CONTRACT.md#g1c-權限與危險操作)

### 成員識別

支出、分攤、結算與還款以 ID 識別本人與虛擬成員。使用目前名冊的姓名；同名附可區分的 ID 尾碼，自六碼起延長。已移除且參照為 null 時只顯示已移除。沒有可用名冊時顯示參照姓名與已知標記，無法保證消歧；已讀名冊後仍有 ID 的歷史非成員加短碼，跨頁歷史名冊可能不完整。畫面及讀屏採同一個標籤。

## 行程日與活動

成員在「行程」分頁切換已建立的日卡，閱讀活動、地點、備註及成員訂位碼。無開始日期時使用 Day 編號，Markdown 日說明以完整原文呈現。正向跨日的延續提示可打開原活動詳情並返回原位置；票券附件與 AI 匯入留在 Web。[版面與跨日規格](../../../docs/design/ITINERARY_PRESENTATION.md)

管理員連線時可新增、編輯、刪除日與活動。改一天的說明會保留當日活動；刪除一天會列出關聯影響，其他日保留原編號。活動可填當地起迄時間、結束日、地點、備註與訂位碼；只有明確起訖日才推導日差。檢視時重讀版本，有差異須再次確認。已消失的目標不能當新活動送出。[原生編輯與恢復](ARCHITECTURE.md#app-行程日維護與恢復)

同日多選使用獨立操作頁，每批最多 15 項；勾選後先重讀影響，失效的項目要明確移除。全選刪除仍保留空日、支出、相片與個人成就。已確認的請求以原 UUID 查回。BD1／BD2 的審查已通過，操作驗收範圍見 [同日多選收尾](../../../docs/design/ITINERARY_BATCH_DELETE.md#本項目收尾)。

## 支出、預算與結算

### G3b-1 進階新增與草稿

新增時選付款人、日期、原幣、匯率與分攤對象，支援均分、固定原幣金額、百分比及份數。不同模式分別保存逐人輸入，切換後可以回來續填。參考匯率須明確套用；保存草稿保留原輸入與完整匯率。後端預覽列出基準金額及各人份額，改動任何輸入都需重新預覽。確認後固定原內容與 UUID。[預覽與寫入契約](BACKEND_CONTRACT.md#g3a-2-進階分攤新增與編輯)

### G3b-2 進階支出編輯

基本編輯只修改說明、分類或日期，保留歷史付款人、原幣、匯率、份額、標籤、附件與行程關聯。使用者明確選擇重新分攤後才輸入新模式與付款人，預覽並核對新舊份額；缺少原模式的舊資料不反推。刪除支出前會重讀最新內容並顯示確認。[編輯資料流](ARCHITECTURE.md#g3b-2-進階編輯資料流)

- **明細與收據。** 支出清單依日期分組，可分頁、下拉更新與閱讀分攤。私人收據支援拍照、選圖、PDF、讀取與移除；上傳完成、附件正式關聯及結果未知是不同狀態。[附件確認與恢復](ARCHITECTURE.md#g6b-附件確認與恢復)
- **預算與搜尋。** 概覽可設定本人總額及分類預算，進度採已入帳的個人分攤。旅內搜尋／篩選與分析依授權的全旅行資料計算，未載入的分頁也納入。[預算](BACKEND_CONTRACT.md#g4a-個人預算) · [搜尋與分析](BACKEND_CONTRACT.md#g4b-搜尋與分析)
- **結算與還款。** 結算顯示本人應收／應付、全員餘額、轉帳建議與已登記還款。按建議或手動登記均使用旅行基準幣別，可部分、超額付款或撤銷誤登；App 記錄已發生的付款，實際金流由成員處理。[還款契約](BACKEND_CONTRACT.md#e4-登記與撤銷還款)

## 離線、待處理與復原

| 使用者看到的狀態     | 可以做什麼                                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 本機草稿             | 每個環境／帳號／旅行保留一份原始輸入。已在線上取得最小成員選項的旅行可離線建立、續填或捨棄。冷啟動須有先前驗證的本機身分 |
| 已確認均分、尚待送出 | 限 TWD 帳本、TWD 原幣及均分。恢復前景與連線後重驗成員、預覽與權限，同一 UUID 只入帳一次。其他幣別或模式先存草稿          |
| 已送出、結果未知     | 固定原內容與 UUID，依該操作查詢或明確重試；收到 429 遵守等待期限。成功後只刷新資料；終局拒絕依操作恢復原輸入             |
| 失去旅行存取權       | 隱藏私人資料。斷線或晚到回應不能解除已知拒絕；換帳號不會送出原帳號的工作                                                 |

SQLite 保存草稿與待處理紀錄，帳務查詢只保留於本次記憶體。離線本機入口與完整線上帳務的邊界見 [裝置儲存](../src/storage/README.md)。裝置故障、外部郵件／R2、VoiceOver 與 Android 的驗收分別記在 [本機驗收](LOCAL_ACCEPTANCE.md)。
